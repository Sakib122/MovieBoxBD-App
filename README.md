# 🎬 MovieBoxBD — Android অ্যাপ v2.0 (সম্পূর্ণ ফ্রি)

তোমার ওয়েবসাইট **movieboxbd.xyz** থেকে সরাসরি ডেটা নিয়ে চলা আসল Android অ্যাপ।
কোনো সার্ভার খরচ নেই — সবকিছু GitHub Actions দিয়ে **ফ্রিতে** বিল্ড হয়।

## ⚙️ Config.kt-তে যা যা বসাতে পারো

| কী | কাজ |
|---|---|
| `TELEGRAM_BOT_USERNAME` | তোমার বটের ইউজারনেম (@ ছাড়া) দিলে ✈ বাটন চালু হবে |
| `AD_WATCH_SECONDS` | অ্যাড দেখার সময় (ডিফল্ট ১০ সেকেন্ড) |
| `POPUNDER_EVERY_N` | কতবার মুভি ওপেনে ১ পপআন্ডার (ডিফল্ট ২; প্রতিবার চাইলে ১) |
| `BANGLA_DUB_LABELS` | ব্লগে "Bangla Dub" লেবেল দিলেই অ্যাপে সেকশন অটো আসবে |
| `ADSTERRA_DIRECT_LINK` | তোমার Direct Link (বসানো আছে) |
| `ADSTERRA_BANNER_320x50` / `_300x250` | তোমার ব্যানার কোড (বসানো আছে) |

বদলানোর পর Commit দিলেই অটো নতুন APK! 🔄

## 🔇 সাউন্ড নোট

- ExoPlayer বেশিরভাগ ফোনে Dolby (DDP5.1) সাউন্ডও চালায়।
- যে ফোনে সত্যিই সাপোর্ট নেই — ছবি চলতে থাকবে + মেসেজ দেখাবে, ক্র্যাশ হবে না।
