# 🎬 MovieBoxBD — Android অ্যাপ (সম্পূর্ণ ফ্রি)

তোমার ওয়েবসাইট **movieboxbd.xyz** থেকে সরাসরি ডেটা নিয়ে চলা আসল Android অ্যাপ।
কোনো সার্ভার খরচ নেই — সবকিছু GitHub Actions দিয়ে **ফ্রিতে** বিল্ড হয়।

| ফিচার | কীভাবে কাজ করে |

> **ব্লগে নতুন পোস্ট দিলেই অ্যাপে অটো চলে আসবে** — অ্যাপ আপডেট দিতে হবে না।

## 🚀 কীভাবে GitHub-এ তুলবে (মাত্র ৫ স্টেপ)

1. **ZIP আনজিপ করো** — `MovieBoxBD-App` ফোল্ডারটা পাবে।
2. **GitHub-এ নতুন রিপো খোলো** → https://github.com/new
   - নাম দাও: `MovieBoxBD-App`
   - **Public** রাখো (ফ্রি আনলিমিটেড বিল্ডের জন্য)
   - "Add a README" ❌ **টিক দিও না** — খালি রাখো
3. রিপো পেজে **"uploading an existing file"** লিংকে ক্লিক করো।
4. **আনজিপ করা ফোল্ডারের ভেতরের সবকিছু** (`.github`, `app`, `build.gradle` ইত্যাদি) ড্র্যাগ করে ছাড়ো — ফোল্ডার স্ট্রাকচার নিজে থেকেই ঠিক হবে। ⚠️ ZIP ফাইলটা না, ফোল্ডারের ভেতরের জিনিসগুলো!
5. নিচে **"Commit changes"** চাপো।

ব্যাস! 🎉 **Actions ট্যাবে গিয়ে দেখো — APK বিল্ড শুরু হয়ে গেছে।**
৩-৫ মিনিট পর **Releases** সেকশনে গেলে `MovieBoxBD.apk` পাবে — সেটাই ইউজারদের দেবে।

## 💰 তোমার Adsterra অ্যাড (আগে থেকেই বসানো আছে!)

`app/src/main/java/com/movieboxbd/app/Config.kt` ফাইলে:

- ✅ **Direct Link** — তোমার সাইটে যেটা চলছে (`effectivecpmnetwork.com/...key=...`) সেটাই বসানো।
  ইউজার **▶ প্লে** চাপলে প্রতি ৬ ঘণ্টায় ১ বার এটা খুলবে (তোমার সাইটের পপআন্ডারের মতই)।
- 🟡 **ব্যানার** — এখনো তোমার সাইটে ব্যানার জোন নেই, তাই খালি। চাইলে:
  Adsterra Dashboard → Websites → নতুন **Banner** জোন → কোড কপি →
  Config.kt-র `ADSTERRA_BANNER_HTML = ""` — কোটের ভেতরে পেস্ট করো।

বদলানোর পর Commit দিলেই অটো নতুন APK! 🔄

### অন্য সেটিংস (একই ফাইলে)

| কী | কাজ |
|---|---|
| `CATEGORY_LABELS` | ক্যাটাগরি চিপস — ব্লগের Label-এর সাথে হুবহু মিলিয়ে লিখো |
| `TELEGRAM_URL` | তোমার চ্যানেল লিংক দিলে ডিটেইল পেজে টেলিগ্রাম বাটন আসবে |
| `DIRECT_LINK_COOLDOWN_HOURS` | কত ঘণ্টা পরপর ডায়রেক্ট লিংক খুলবে |
| `strings.xml`-এ `app_name` | অ্যাপের নাম বদলাতে |

## 📲 ফোনে ইনস্টল (প্রথমবার)

1. APK ডাউনলোড করো (GitHub Releases / এই প্যাকেজের `MovieBoxBD.apk`)
2. ট্যাপ করলে বলবে **"Install unknown apps"** → অনুমতি দাও (Play Store বাইপাস, একবারই)
3. ইনস্টল → খোলো 🎬

## 🔇 সাউন্ড নোট (গুরুত্বপূর্ণ)

- ব্রাউজারে Dolby (DDP5.1/AC3) মুভির সাউন্ড আসত না — **অ্যাপে ExoPlayer বেশিরভাগ ফোনেই সাউন্ড দেয়।**
- যে ফোনে সত্যিই সাপোর্ট নেই, অ্যাপ অটো ছবি চালিয়ে দেবে + মেসেজ দেখাবে — ক্র্যাশ হবে না।
