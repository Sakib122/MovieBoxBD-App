# 🎬 MovieBoxBD — Android অ্যাপ v2.0 (সম্পূর্ণ ফ্রি)

তোমার ওয়েবসাইট **movieboxbd.xyz** থেকে সরাসরি ডেটা নিয়ে চলা আসল Android অ্যাপ।
কোনো সার্ভার খরচ নেই — সবকিছু GitHub Actions দিয়ে **ফ্রিতে** বিল্ড হয়।

## 🔔 v5.6 — গেট-বিপ: অ্যাডের সময় শেষ হলেই ফোন-কলের মতো জোরে **একটাই** ভাইব্রেট + বিপ (মালিকের নির্দেশ)

| পরিবর্তন | বিস্তারিত |
|---|---|
| 🔔 গেট-বিপ | ইউজার অ্যাড দেখতে ব্রাউজারে গেলে অ্যাপ নিজে থেকেই বাকি সেকেন্ড গুনে বসে — **ঠিক সময় পূর্ণ হওয়ার মুহূর্তে** ফোন **ফোন-কলের মতো জোরে ভাইব্রেট** করবে (**টানা ২.৩ সেকেন্ডের একটাই ফুল-শক্তি ধাক্কা** — মালিকের নির্দেশ: তিনবার নয়, একবারই) + স্ক্রিনে **«🔔 বিপ! অ্যাডের সময় শেষ»** হেডস-আপ নোটিফিকেশন + বিপ শব্দ। ইউজার ব্রাউজারে বসে বসে সময় হিসাব রাখবে না — ফোন কাঁপলেই বুঝবে ফিরার সময় হয়েছে। |
| 💯 ভাইব্রেশন ১০০% আমাদের হাতে | নোটিফিকেশন-চ্যানেলের নিজস্ব ভাইব্রেশন বন্ধ — ভাইব্রেশন সরাসরি Vibrator API দিয়ে হয়, তাই ফোন-সেটিং/টেলিগ্রাম-সেটিং যা-ই থাকুক, কলের মতোই কাঁপবে (টেলিগ্রাম-বটে যেটা পারা যেত না, অ্যাপে সেটাই পারা যায়)। |
| 👆 ট্যাপ করলেই অ্যাপ | নোটিফিকেশনে ট্যাপ করলে সরাসরি অ্যাপ খোলে — ব্যাক-বাটন খোঁজার দরকারই নেই; ফিরে এলেই মুভি প্লে / ডাউনলোড / টেলিগ্রাম সাথে সাথে। |
| ▶ কোথায় কোথায় | **সব গেটেই** — ▶ প্লে, ⬇ ডাউনলোড, 🌐 ব্রাউজার, ✈ টেলিগ্রাম এবং ⏮⏭ এপিসোড-সুইচ। |
| 🎯 নির্ভুল সময় | বাকি সেকেন্ড শুধু অ্যাড-পেজে থাকার সময়ই গোনা হয় (আগের নিয়ম) — বিপ-অ্যালার্মও ঠিক সেই হিসাবেই বাজে; আগে ফিরে এলে অ্যালার্ম বাতিল, পুরো দেখলে ছোট খুশির **এক ধাক্কা** (কাজ হয়ে গেছে সংকেত)। |
| 📢 ইউজার আগেই জানবে | গেট শুরুর টোস্টে, এপিসোড-গেট ওভারলেতে আর সতর্কবার্তা-ডায়ালগে এখন লেখা থাকে: «সময় শেষ হলেই ফোন জোরে ভাইব্রেট করবে + বিপ শুনবে» — কেউ অনুমান করতে বসে থাকবে না। |
| 🛡 নির্ভরযোগ্যতা | তিন স্তরের ফলব্যাক: ① অ্যাপ-প্রসেস জীবিত থাকলে Handler-টাইমার **সেকেন্ড-নির্ভুল** বাজে — ওপো/আইটেল/স্যামসাং-এর ব্যাটারি-ম্যানেজারও দেরি করাতে পারে না ② প্রসেস মরলেও AlarmManager জাগিয়ে দেয় ③ নোটিফিকেশন আটকে গেলে (পারমিশন নেই) নিজেই রিংটোন বাজায়। সাইলেন্ট মোডেও ভাইব্রেশন কাজ করে। |
| 🏷️ ভার্সন | versionCode 31, versionName 5.6। বদলানো: `GateAlert.kt` (এক ধাক্কা + Handler-টাইমার)। বাকি সব ফাইল v5.5-এর মতোই। |

## 🛡 v5.3 — ডাউনলোড-সেক্টরের নিজস্ব গেট + নরমাল/১৮+ আলাদা হিসাব + রিফ্রেশে রিসেট (মালিকের নির্দেশ)

| 🔞 আলাদা কাউন্ট | নরমাল আর ১৮+ **প্লে** এখন দুই আলাদা ঘড়িতে: নরমালের গেট পার হলে শুধু নরমাল প্লে ফ্রি (২ মিনিট), ১৮+ নিজের গেট দেখে নিজের ২ মিনিট পায়। ১৮+ ডাউনলোডের নিয়মও সব জায়গায় এক — প্রতিবার গেট। |

## 💰 v5.0 — অ্যাড-সিস্টেম নতুন রূপ (রিয়েল-কোয়ালিটি গেট + প্যানেল-কন্ট্রোল)

| পরিবর্তন | বিস্তারিত |
|---|---|
| 🛡 রিয়েল-কোয়ালিটি গেট | সময় শুধু **অ্যাড-পেজে থাকার সময়ই** গোনা হয় — অ্যাপে ফিরে বসে থাকলে টাইমার এগোয় না। সময়ের আগে ফিরলে সতর্কবার্তা: "আরও X সেকেন্ড বাকি ছিল" → আবার অ্যাড দেখে ফিরতে হবে; পুরোটা দেখলে ফিরেই প্লে। |
| ⏱ ৫ → ১০ সেকেন্ড | গেটের ডিফল্ট সময় এখন ১০ সেকেন্ড (প্যানেল থেকে ৫–৬০ সেকেন্ড যেকোনো সময় বদলানো যায়) |
| 🚫 ব্যানার সম্পূর্ণ বাদ | মৃত ইমপ্রেশন CPM নামাত — এখন ইনকাম শুধু রিয়েল গেট-ভিউতে। পপ-আন্ডারও নেই (ইউজার বিরক্ত হয় না) |
| ☁️ অ্যাডমিন প্যানেল থেকে সব কন্ট্রোল | MovieBoxBDStreamBot-এর `/admin` প্যানেলে "💰 অ্যাপের অ্যাড কন্ট্রোল" সেকশন — গেট চালু/বন্ধ, সেকেন্ড, কুলডাউন, নরমাল + ১৮+ লিংক পুল সেভ করলেই সব রানিং অ্যাপে সাথে সাথে বসে (RemoteAds.kt) |
| 🔞 নরমাল / ১৮+ আলাদা | সাধারণ মুভি → শুধু নরমাল পুল, ১৮+ মুভি → শুধু অ্যাডাল্ট পুল — কোডে মেশার কোনো পথ নেই |
| 🚫 বাইপাস-প্লাগ | গেট বাতিল করে সাথে সাথে আবার চাপলে আগে অ্যাড-ছাড়া চলে যেত — এখন বাতিল করলেই কুলডাউন-ফাঁক বন্ধ, পরের ক্লিকে আবার গেট |
| 📊 গেট-হিসাব প্যানেলে | আজ কতজন পুরো দেখল (gate_pass), কতজন আগে-ফেরত (gate_fail), কতজন বাতিল (gate_cancel) — প্যানেলের অ্যাড-সেকশনে লাইভ |

লিংক পুল বদলাতে এখন কোড কমিট লাগে না — প্যানেল থেকেই হয়; প্যানেল খালি/সার্ভার বন্ধ হলে
`Config.kt`-র বিল্ট-ইন লিংকই চলে। অ্যাডমিন প্যানেল রিপো: **MovieBoxBDStreamBot**।

## ⚙️ Config.kt-তে যা যা বসাতে পারো

| কী | কাজ |
|---|---|
| `TELEGRAM_BOT_USERNAME` | তোমার বটের ইউজারনেম (@ ছাড়া) দিলে ✈ বাটন চালু হবে |
| `AD_WATCH_SECONDS` | অ্যাড দেখার সময় (ডিফল্ট ১০ সেকেন্ড) |
| `POPUNDER_EVERY_N` | কতবার মুভি ওপেনে ১ পপআন্ডার (ডিফল্ট ২; প্রতিবার চাইলে ১) |
| `BANGLA_DUB_LABELS` | ব্লগে "Bangla Dub" লেবেল দিলেই অ্যাপে সেকশন অটো আসবে |
| `ADSTERRA_DIRECT_LINK` | তোমার Direct Link (বসানো আছে) |
| `ADSTERRA_BANNER_320x50` / `_300x250` | তোমার ব্যানার কোড (বসানো আছে) |
